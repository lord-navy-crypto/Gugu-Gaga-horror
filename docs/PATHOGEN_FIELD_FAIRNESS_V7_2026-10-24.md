# Pathogen information field V7: fair updates and inspection

The existing 15-channel location-based game data field remains unchanged in representation. This PR fixes a source-data scheduling error: formerly environmental route events always examined the lexicographically first occupied cells of every dimension. With hundreds of persistent game-data cells, later cells could never receive a route event. A dedicated `PathogenRouteFairScheduler` now visits 64 different existing cells per step, with a persisted `RouteCursor` in per-dimension SavedData. At 1,024 occupied cells, **every cell is scanned over 16 route-update cycles** (as an upper bound in a static field, regardless of whether a route is active). An actual transfer requires separately passing loaded/near-player and eligible-game-channel guards; visiting does not guarantee a transfer.

The movement-trail cache now retains up to 256 recently observed animal UUID/cell pairs with deterministic oldest-entry eviction. The previous per-frame `retainAll(observedAnimals)` could discard other moving animals under the 64-event budget. No history uses a persistent infected status or stores an animal entity or live world reference; histories are ephemeral during the server session. Player offline entries are still removed. The game logic, numeric 0–15 units, 1,024 sparse-cell cap and loaded-chunk rule remain as before.

For inspection, `/gugugaga field map <taxon>` displays a purely textual **7×7** 4-block-cell mini heatmap centered on the player's position: `0` means no field signal, `1..9` low-to-medium game numbers, and `A..F` game numbers 10–15. Map runs as a player with no operator permission; seeding and clearing remain operator-gated. The heatmap creates no extra blocks, mobs, biome replacements, interactive infection effects, or particle-intensive overlays. This is not clinical, biological or exposure information.

Acceptance includes 1,024-cell round-robin sweeps and tests proving no skipped cell across 16 updates, invalid budget rejection, save cursor wiring, display channel independence, Gradle build and real client/server startup CI. Manual Minecraft tests of cross-world saves, unloaded-player regions, split-screen or multiplayer chat displays remain separate.
