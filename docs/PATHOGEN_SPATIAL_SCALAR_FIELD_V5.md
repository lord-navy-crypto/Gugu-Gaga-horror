# Pathogens as position-bound DATA, not blocks or mobs

This PR changes the main pathogen-system architecture into **15 per-position integer pressure channels**, stored in sparse world-per-dimension SavedData. A game cell equals one 4x4-block horizontal region; this is a data record, not a Minecraft block, BlockEntity, or living microbe Entity. Max 1024 occupied cells per dimension and 15 values per cell, all in the range 0..15. Empty cells occupy no records. Existing old decorative microbe blocks are legacy content, never the source of pathogen field state.

World updates are server-owned and happen each 80 game ticks. The pure Java `PathogenSpatialFieldMath` visits up to 64 currently enrolled cells per dimension, uses a simultaneous snapshot and at most one purely fictional unit per channel per selected source to one of four adjacent active loaded cells, with gradual fictional decay. NO game coefficient is inferred from the named real taxa. No real laboratory transmission, infection kinetics, airborne behavior, infectious dose, survival calculation, exposure assessment or clinical prediction is performed. All 15 taxa currently have exactly the same game-field update and no infection or host-to-host contagion.

The existing V4 hand scanner already works on compatible animals/crops/trees; selecting a new scenario now also registers abstract field pressure on the object's current 4x4 Minecraft region. A game moderator can inspect any area with `/gugugaga field status`, seed a chosen catalog label with `/gugugaga field seed <taxon>` or clear it with `/gugugaga field clear <taxon>` (seed/clear require operator permission 2). World players in a nearby occupied field get bounded periodic game-pressure observations and a tiny original particle cue, NOT an infection result. Vanilla crops can optionally experience a reversible pause at high abstract pressure when their visual-proxy mapping matches the active field species. No special pathogen blocks or entities are spawned and no original vanilla terrain is changed.

Future work: more precise region granularity, stress-test snapshot and NBT save/reload; host/player effect adapters must remain clearly separated from scientific infectiousness. Main stable branch remains unchanged until PR verification.
