# Living microbe simulation on real Minecraft animals (not blocks)

This experimental branch finally changes the architecture away from custom organism blocks. The key object is a real Minecraft ANIMAL, selected using a craftable Living Microbe Field Scanner. Interacting with chicken, parrot, cow, pig, sheep, wolf, fox, cat, or horse creates a deliberately **virtual** per-mob micro-ecology record in that mob's persistent NBT. Nearby animals without an explicit scan are left alone. Each enrolled mob gets a bounded simulation update every 80 game ticks while loaded and within 16 blocks of an online player. The server limits processing to 128 enrolled animals per update and deduplicates overlapping observers by UUID. Native small particles follow the moving animal.

Right-click the enrolled mob again for a numeric GAME-unit observation. Sneak-right-click cycles three scenario modes: bacterial flora, T4 phage-to-E. coli bacterial-host study, and appropriate animal-virus scenario (avian influenza context on birds; rabies context on a small explicit mammal allowlist). Modes are chosen by the player, not by hidden auto-infection of all wolves/chickens. The values are **abstract Minecraft markers**, not microbial cell counts, virion counts, real replication rates, strain susceptibility, disease diagnosis, transmission probabilities or medical data. In the phage view the bacterial marker fluctuates with a toy host interaction; virus markers pulse only for selected compatible game scenarios. They never infect another mob or the player.

This distinguishes a server-side game engine from an encyclopedia page: the bacteria marker changes as Minecraft weather changes, T4 phage interaction changes the bacterial marker, and the active animal-virus view changes with time. All states are persisted on actual animal entities and presented through the field scanner plus native in-world particle clues. It does NOT create new blocks, spawn one Entity per actual bacterium or force chunks. It does not change vanilla animal health/speed or self-propagate true diseases.

The broader scientific links still use real NCBI, CDC and WHO taxon/host categories in the existing NaturalMicrobeCatalog and OneHealthEvidenceCatalog. This engine is intentionally not quantitative epidemiology or laboratory microbiology. Next: investigate scanned-mob NBT persistence after unload/reload, visualization on actual farm animals, multiplayer ownership and permissions, and integration with in-game veterinary/medical gameplay. Stable main is not changed.
